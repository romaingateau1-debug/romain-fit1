ROMAIN FIT — PWA

Installation iPhone:
1. Héberge ce dossier sur un site HTTPS (GitHub Pages, Netlify, Vercel, etc.).
2. Ouvre l'adresse dans Safari sur l'iPhone.
3. Appuie sur Partager.
4. Choisis « Sur l'écran d'accueil ».
5. Ouvre Romain Fit depuis l'icône : l'app se lance en mode plein écran.

Les données sont stockées localement sur l'appareil via localStorage.
Le service worker permet le fonctionnement hors connexion après la première ouverture.
